# tft基米助手 v1.2.10 更新说明

> 一个云顶之弈 S19（PBE）阵容 / 装备 / 强化查询 App。这一版把 dataTFT 的攻略和阵容整套接了进来，阵容从 60 套变成 79 套。

---

## 这次最值得说的：阵容不再只有 MetaTFT 一家

以前 App 里的阵容全部来自 MetaTFT 的战绩统计，优点是数据准，缺点是**只有数据、没有思路**——你知道这套牌前四率 62%，但不知道开局该抢什么、几级 D 牌、什么时候上人口。

这一版接入了 dataTFT 的攻略库，两边各取所长：

- **战绩数字**（排名 / 前四率 / 吃鸡率 / 登场率）仍然来自 MetaTFT，按真实对局统计；
- **打法思路**（核心思路、开局条件、前期运营、中期节奏、成型后期、克制与注意）来自 dataTFT 的玩家投稿攻略；
- 两边能对上的 21 套阵容，现在同一个详情页里既有数据又有攻略；对不上的 19 套 dataTFT 独有阵容，也一并进了列表。

**阵容总数：60 → 79 套。**

## 详情页现在长这样

页签结构跟 MetaTFT 阵容完全一致：**概览 / 英雄 / 装备 / 过渡 / 变阵 / 攻略**。

- **概览**：棋盘按 dataTFT 站点自己的站位逐格还原，谁站前排、谁站后排、带什么装备，一眼能对上。
- **英雄**：每个英雄 + 它的三件成型装备，直接照抄就能打。
- **攻略**：六段式文字攻略 + 前四率 / 登顶率 / 平均排名。
- **过渡 / 变阵**：dataTFT 没有这部分数据，页面会明确写「未提供」，不会拿假数据糊弄。

## 两个容易被忽略的细节

**1. 登场率不是一个口径，我们做了换算。**
dataTFT 的「对局出现率」是「这局里有没有人玩这套」（一局 8 个人），MetaTFT 的「登场率」是「玩这套的玩家占比」。直接摆一起会看起来差 8 倍。这一版按 `1-(1-p)^(1/8)` 做了换算，现在两个数字可以直接横向比。

**2. 等级不再自己算。**
dataTFT 阵容的 S/A/B/C/D 直接采用站点自己的评级，不再用我们的百分位重算——避免出现「同一个阵容，App 说 A，官网说 S」这种尴尬。

## 顺手修的

- 装备页不再显示虚假的「影响 -4.50」。
- 召唤物（亚托克斯之类）不会在棋盘上多占一格。
- 「英雄」页签不再出现 `TFT_Item_NeedlesslyLargeRod` 这种原始字段串。

## 怎么更新

到 GitHub Releases 下载最新 APK 覆盖安装即可，签名不变，可以直接盖在旧版上：

**https://github.com/9agj/tft-kimi-assistant/releases**

App 内「设置 → 版本与更新 → 检查更新」也会提示新版本。

## 数据说明

- 战绩数据：MetaTFT，每 4 小时抓一次。
- 攻略数据：dataTFT，每天两次。
- 两者独立统计，口径不同，页面里已分别标注。
